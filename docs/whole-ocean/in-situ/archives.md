# :material-database-outline: Multi-platform Archives <span class="date">[2026.03.28]</span>

Databases that gather profiles from many platforms (ships, Argo, moorings, gliders) into one archive.
For a single platform, see the [Argo](argo.md), [Drifter](drifter.md), [Ship](ship.md) and [Mooring](mooring.md) pages.

## Global profile databases

<div class="grid cards" markdown>

-   **World Ocean Database (WOD)**

    ---

    NOAA NCEI's global archive of in situ ocean profiles

    [:octicons-link-external-24: WOD (NOAA NCEI)](https://www.ncei.noaa.gov/products/world-ocean-database)<br>
    [:octicons-arrow-right-24: How to download WOD](wod-download.md)<br>
    [:octicons-arrow-right-24: World Ocean Atlas (WOA)](../../processed/woa.md)

-   **GTSPP**

    ---

    Global Temperature and Salinity Profile Programme, run jointly by WMO and IOC; long-term archive at NCEI

    [:octicons-link-external-24: GTSPP (NOAA NCEI)](https://www.ncei.noaa.gov/products/global-temperature-and-salinity-profile-programme)

-   **CODC-v1** · 1940–2023

    ---

    Quality-controlled and bias-corrected temperature profile database

    [:octicons-book-24: Scientific Data (2024)](https://www.nature.com/articles/s41597-024-03494-8#code-availability)<br>
    [:octicons-download-24: Marine Science Data Center (CAS)](https://msdc.qdio.ac.cn/data/metadata-special-detail?id=1614882932315443202&otherId=1614882932386746369)

-   **CODC-v2**

    ---

    Global ocean in situ profile observational dataset

    [:octicons-download-24: Marine Science Data Center (CAS)](https://msdc.qdio.ac.cn/data/metadata-special-detail?id=1866385243443826689&otherId=1866385243481575426)

</div>

## Coriolis / CMEMS

<div class="grid cards" markdown>

-   **CMEMS CORA (profiles)** · instantaneous, L2 · 1950-01-01 – 2021-12-31

    ---

    Profiles collected from the major global networks: Argo, GOSUD, OceanSITES, World Ocean Database and others

    [:octicons-link-external-24: INSITU_GLO_PHY_TS_DISCRETE_MY_013_001](https://data.marine.copernicus.eu/product/INSITU_GLO_PHY_TS_DISCRETE_MY_013_001/description)

-   **Coriolis Center**

    ---

    Browse, select and download observations from the Coriolis big-data infrastructure

    [:octicons-link-external-24: Coriolis: Find data](https://coriolis-93c5db.gitlab-pages.ifremer.fr/find-data.html)<br>
    [:octicons-download-24: Coriolis data selection](https://data-selection.odatis-ocean.fr/coriolis)<br>
    [:octicons-link-external-24: CORA (SEANOE)](https://www.seanoe.org/data/00351/46219/)

</div>
