# :material-earth: NEAR-GOOS <span class="date">[2026.04.15]</span>

North-East Asian Regional Global Ocean Observing System: a joint program of China, Japan, Korea and Russia.
JMA hosts the real-time database (RRTDB) and JODC the delayed-mode database (RDMDB).

    ---
