# :material-earth: NEAR-GOOS <span class="date">[2026.04.15]</span>

North-East Asian Regional Global Ocean Observing System. 대한민국, 일본, 중국, 러시아 공동 프로젝트입니다.
실시간 데이터베이스(RRTDB)는 JMA가, 지연 모드 데이터베이스(RDMDB)는 JODC가 운영합니다.

<div class="grid cards" markdown>

-   **NEAR-GOOS RRTDB (JMA)**

    ---

    Regional Real Time Data Base. JMA가 제공하는 단면 자료입니다.

    [:octicons-link-external-24: NEAR-GOOS RRTDB](https://www.data.jma.go.jp/goos/data/rrtdb/cross-section/cross-section.html)

-   **RDMDB Data Retrieval System (JODC)**

    ---

    Regional Delayed Mode Data Base. 자료를 내려받는 링크입니다.

    [:octicons-download-24: RDMDB 검색](https://near-goos1.jodc.go.jp/vpage/search_en.html)<br>
    [:octicons-link-external-24: List of retrievable RDMDB data](https://near-goos1.jodc.go.jp/rdmdb/datalist.html) (어떤 자료가 어떤 포맷으로 제공되는지 확인)

-   **J-DOSS: JODC Data On-line Service System**

    ---

    JODC가 일본 안팎 연구기관의 해양 자료와 관련 정보를 수집·보관하여 제공하는 시스템입니다.

    [:octicons-link-external-24: J-DOSS](https://www.jodc.go.jp/jodcweb/JDOSS/index.html)

</div>
